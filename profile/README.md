# BioRewired

EEG designs, session review and feedback in one experimental Windows workspace.

BioRewired brings together **Design & Training**, **Easy Training**, **Session Review** and the **Feedback Player**. The suite uses a single **BIOREWIRED.exe** launcher, with starter designs and feedback games including Racer.

## Start with the software demo

Extract the complete Windows package, open **BIOREWIRED.exe**, then use **Easy Training → one-channel starter → Open demo → Play recording → Open Player → Enable feedback → Games/Racer**. Test live amplifier input separately after stopping the demo. Keep your working installation and original files intact.

The beta is still being developed. The 66-issue work, broader device/design compatibility and calibration remain open. Do not treat a moving trace or a completed software demo as validation of live EEG measurements.

**Experimental software, not clinically validated and not for diagnosis, treatment or clinical decisions.** Example designs are software demonstrations, not treatment recommendations.
